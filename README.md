# Poco X3 Pro Simulator
Первая структура Android-проекта симулятора Poco X3 Pro.

## Модули
- Телефонный интерфейс
- Производительность
- Батарея
- Температура
- Игровой режим
- Система улучшений
- Tool с механикой броска и восстановлением за 1 секунду
